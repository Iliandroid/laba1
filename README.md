[Задача №325 на Informatics](https://informatics.msk.ru/mod/statements/view.php?chapterid=325)

Упорядочить точки по расстоянию от начала координат. Хранить координаты в структуре Point; в Python используется класс Point.

$$
d^2=x^2+y^2.
$$

### Формат входных данных

Количество точек $n\le100$, затем $n$ строк с целыми координатами $x$ и $y$.

### Формат выходных данных

Координаты точек в порядке возрастания расстояний. Количество точек выводить не нужно.

### Пример

**Входные данные**

```text
3
3 4
0 0
1 1
```

**Выходные данные**

```text
0 0
1 1
3 4
```
