## Как читать код

Индексы списков начинаются с нуля. Комментарии после `#` объясняют код и не исполняются. Отступы определяют, что находится внутри функции, цикла или условия. `=` присваивает значение, `==` сравнивает, `+= 1` увеличивает на один. `range(n)` даёт индексы от 0 до n−1. Рекурсия — вызов функцией самой себя для меньшей задачи; условие остановки не даёт ей продолжаться бесконечно.

## H · Сортировка точек

[Условие](https://informatics.msk.ru/mod/statements/view.php?chapterid=325) · [Код](lab8.py)

Создаём класс Point с координатами x и y. Сортируем объекты вставками по квадрату расстояния. При одинаковых расстояниях сохраняем исходный порядок.

**Ввод:** N ≤ 100, затем N строк с двумя целыми координатами.

**Вывод:** Координаты по возрастанию расстояния от начала координат, без повторного вывода N.

**Время:** $O(n^2)$. **Дополнительная память:** $O(1)\text{ сверх списка точек}$. Хранение исходного списка требует $O(n)$.

**Принятая посылка:** №42529977.

## Формулы

Число сравнений в простых сортировках:

$$\sum_{i=1}^{n-1}i=\frac{n(n-1)}{2}=O(n^2).$$

В D число обменов совпадает с числом инверсий — пар, стоящих в неправильном порядке:

$$I=|\{(i,j):i<j,\ a_i>a_j\}|.$$

Для слияния:

$$T(n)=2T(n/2)+O(n)=O(n\log n).$$

Для точки:

$$d=\sqrt{x^2+y^2},\qquad d^2=x^2+y^2.$$

Квадратный корень возрастает, поэтому сравнение квадратов расстояний даёт тот же порядок. Например, точка (1, 1) ближе, чем (3, 4): $2<25$.
